# 茶安智检小程序（局域网版）

通过微信开发者工具在手机上使用，访问局域网内的检测服务器（192.168.1.100），全程不需要外网。

## 学生快速开始

1. 安装微信开发者工具（稳定版）。
2. 导入本文件夹；AppID 一栏选「测试号」（有自己 AppID 的也可以填自己的）。
3. 右上角「详情 - 本地设置」确认勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」（项目配置里已默认关闭，导入后确认一下即可）。
4. 手机和检测服务器（192.168.1.100）连接同一个 WiFi/路由器。
5. 点工具栏「预览」，用微信扫码，即可在手机上使用。

## 服务器地址

- 默认：http://192.168.1.100:26711
- 服务器 IP 变化时：修改 utils/config.js 里的 BASE_URL 一行，保存后重新编译。
- 服务器开机后各服务自动启动，无需手动开启；页面如提示后端不可达，先确认服务器已开机、且手机与服务器在同一网段。

## 注意

- 局域网 http 请求只能在「开发版/预览/真机调试」中使用，这是微信平台的限制；正式发布的小程序必须使用 https 域名，不适用于局域网场景。
- 手机如开启了 VPN/代理，请关闭后再试。
- 页面打不开时：先在电脑浏览器访问 http://192.168.1.100:26711/health，能返回 JSON 说明服务器正常，问题在手机侧网络。
